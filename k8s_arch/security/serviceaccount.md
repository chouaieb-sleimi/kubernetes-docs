**overview:**

- **use-cases:**
  - give bots/apps access from outside the cluster
  - give pods access to kubernetes API
- every namespace has a **`default` serviceaccount**
  - pods in that namespace is automatically assigned this serviceaccount (unless otherwise specified)
- **on serviceaccount creation**: generates an access token in a secret object upon creation.

### Enhanced Security Features (Kubernetes v1.22+)

**after v1.22:**
serviceAccounts no longer rely on secret-based tokens. tokens are generated by the **TokenRequestAPI** and are:

- **audience bound:**
  token is restricted to a specific audience (e.g., the Kubernetes API server
- **time bound:**
  token has an expiration time (default of 1 hour)
- **object bound:**
  token is bound to specific objects (pods, serviceaccount, etc.)

**before v1.24:**

- `[serviceAccount [secret [token(doesn't expire)]]]`

**after v1.24:**

- `[serviceAccount [token(default expire after 1h)]]`
- can create a non-expiring token

**Documentation**:

- Service account token Secrets:
  https://kubernetes.io/docs/concepts/configuration/secret/#service-account-token-secrets
- Managing Service Accounts:
  https://kubernetes.io/docs/reference/access-authn-authz/service-accounts-admin/

### Use ServiceAccounts

**attach serviceaccount to pod**

```yaml
apiVersion: v1
kind: Pod
metadata:
  #...
spec:
  containers:
    - name:
      #...
  serviceAccountName: jenkins-sa
```

**on serviceaccount pod attach,** kubernetes automatically:
- creates `ca.crt`, `namespace`, `token` credential files
  - automounts them in `/var/run/secrets/kubernetes.io/serviceaccount`
- kubelet automatically rotates this token
- token is deleted if pod is deleted

**disable default automount**

```yaml
apiVersion: v1
kind: Pod
metadata:
  #...
spec:
  containers:
    - name:
      #...
      automountServiceAccountToken: false
```

**update serviceaccount of a resource**

```bash
kubectl set serviceaccount deploy/web-dashboard dashboard-sa
```

### ServiceAccounts Access Tokens

**create a short-lived access token** in a secret object

> serviceAccount must be created first

```bash
# expires after 1 hour
kubectl create token jenkins-sa [--duration 2h]
```

**create a long-lived access token** in a secret object

```yaml
# doesn't expire
apiVersion: v1
kind: Secret
type: kubernetes.io/service-account-token
metadata:
  name: jenkins-sa
  annotations:
    kubernetes.io/service-account.name: jenkins-sa
```

see sa token

```bash
kubectl describe serviceaccount jenkins-sa | grep -i token

jq -R 'split(".") | select(length > 0) | .[0],.[1] | @base64 | fromjson' <<< <secret_token>
```

**use serviceaccount token**

```bash
curl htts://192.168.56.70:6443/api -insecure \
  --header "Authorization: Bearer <sa_access-token>"
```
