## Install & Configure Package + Network Dependencies

apply the necessary sysctl parameters for networking (enable ipv4 packet forwarding)

```bash
cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
net.ipv4.ip_forward=1
EOF

#Apply sysctl params without reboot

sudo sysctl --system

#verify that net.ipv4.ip_forward is set to 1 with:
sysctl net.ipv4.ip_forward
```

install container runtime

install kubeadm, kubectl and kubelet on all nodes

```bash
sudo apt-get update

sudo apt-get install -y apt-transport-https ca-certificates curl

curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.35/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg

echo 'deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.35/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list

sudo apt-get update

# To see the new version labels
sudo apt-cache madison kubeadm

sudo apt-get install -y kubelet=1.35.0-1.1 kubeadm=1.35.0-1.1 kubectl=1.35.0-1.1

sudo apt-mark hold kubelet kubeadm kubectl
```

## Bootstrap Cluster Using Kubeadm

1. initialize control plane node (master node)
   see: [[installation-kubeadm-control.log]]

```bash
ip -br a
# ...
# 10.244.253.181/32
# ...

kubeadm init \
  --apiserver-cert-extra-sans=controlplane \
  --apiserver-advertise-address 10.244.253.181 \
  --pod-network-cidr=172.17.0.0/16 \
  --service-cidr=172.20.0.0/16
```

2. generate a kubeadm join token (or copy the one that was generated by kubeadm init command)

3. join node01 to the cluster using the join token
   see: [[installation-kubeadm-worker.log]]

```bash
kubeadm join 10.244.253.181:6443 \
  --token dd2zhe.ozd1j92itz4y5553 \
  --discovery-token-ca-cert-hash sha256:fca8e36d91e1370d039df29bb9d6b8c7b74ef5e2b3143395118c32505c821d36
```

## Install Network Plugin (`Flannel`)


download the original yaml file and save it as `kube-flannel.yml:

```bash
curl -LO https://raw.githubusercontent.com/flannel-io/flannel/v0.20.2/Documentation/kube-flannel.yml
```

update PodCIDR the Network field in the kube-flannel-cfg ConfigMap

```bash
net-conf.json: |
    {
      "Network": "10.244.0.0/16", # Update this to match the custom PodCIDR
      "Backend": {
        "Type": "vxlan"
      }
```

args section in kube-flannel container definition should look like this:

```bash
  args:
  - --ip-masq
  - --kube-subnet-mgr
  - --iface=eth0
```

apply the `kube-flannel.yml` manifest

```bash
# apply the modified manifest kube-flannel.yml file using kubectl:
kubectl apply -f kube-flannel.yml

# wait for all the pods to become in the Ready state
watch kubectl get pods -A
# status of both nodes should now become Ready
kubectl get nodes
```
